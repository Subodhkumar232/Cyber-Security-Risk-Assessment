# Cyber Security Risk Assessment

## Overview

This project was completed as part of a Cyber Security Internship task focused on performing a basic cyber security risk assessment for a fictional organization. The objective was to identify critical assets, potential threats, vulnerabilities, and recommend security controls to reduce cyber security risks.

## Organization

Fictional Organization: Online Learning Platform

The platform provides online courses, student accounts, payment services, and educational resources.

## Critical Assets

* Student Information
* User Credentials
* Payment Information
* Learning Management System (LMS)
* Organization Database

## Threats Identified

* Phishing Attacks
* Malware Infections
* Unauthorized Access
* Data Breaches
* Insider Threats

## Vulnerabilities

* Weak Passwords
* Lack of Multi-Factor Authentication
* Unpatched Software
* Poor Security Awareness
* Inadequate Access Controls

## Risk Assessment

| Asset         | Threat              | Vulnerability          | Risk Level |
| ------------- | ------------------- | ---------------------- | ---------- |
| Student Data  | Data Breach         | Weak Passwords         | High       |
| Payment Data  | Unauthorized Access | Lack of MFA            | High       |
| LMS Platform  | Malware             | Unpatched Software     | Medium     |
| User Accounts | Phishing            | Low Security Awareness | High       |

## Recommended Security Controls

* Implement Multi-Factor Authentication
* Enforce Strong Password Policies
* Conduct Security Awareness Training
* Regularly Update and Patch Systems
* Monitor User Activity and Logs
* Perform Regular Backups

## Conclusion

The assessment identified several cyber security risks that could affect the confidentiality, integrity, and availability of organizational assets. Implementing appropriate security controls can significantly reduce these risks and improve the organization's overall security posture.
